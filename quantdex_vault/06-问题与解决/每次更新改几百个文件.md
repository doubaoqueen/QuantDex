# 每次更新 git 里几百个文件变化

## 现象
一次数据更新后，git 显示几百个 parquet 被修改。

## 原因
Parquet 不能追加；每只股票一个文件装 8 年历史 → 每天重写整个文件；
git 对二进制是整文件版本 → 写放大。

## 解决
按日分区（append-only）：
- 入库：`market/daily_by_date/YYYY-MM-DD.parquet`（每天新增 1 个文件）
- 缓存：`market/daily/{code}__qfq.parquet`（gitignore，可重建）

## 自查
更新一天后 `git status` 应只看到 1 个新分区文件（或 registry 一个小改动）。
