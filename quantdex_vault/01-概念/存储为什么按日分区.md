# 存储为什么按日分区

## 一句话
Parquet 不能追加；每只股票一个文件 → 每天重写 8 年历史 → git 里几百个二进制变更。

## 解法
- 入库：`market/daily_by_date/YYYY-MM-DD.parquet`（每天 1 个新文件）
- 缓存：`market/daily/{symbol}__qfq.parquet`（本地，gitignore，可重建）

## 项目里在哪
- `src/data/partitions.py`
- 迁移脚本：`scripts/17_migrate_to_daily_partitions.py`
- 重建：`scripts/18_rebuild_daily_cache.py`
