# 第六篇：从模拟到实践——验证工厂的最后一块砖，居然是钱

项目代号：QuantDex｜纯学习向项目，不构成任何投资建议

导读：四周归因做完的那天晚上，一个外部评审说"你造的不是一个量化系统，是一个能自我说服的验证工厂"。我认。但这一篇要写的不是反思，是一张**终点线**：项目从"模拟"转向"实践"的完整路径——包括一个我憋了三周才发现的事实：**最后一块砖不是技术，是钱**。以及钱到位之前，哪些事现在就能铺。

## 一、终点线的发现：绕不开的 QMT

A 股自动化交易的门票叫 **QMT/PTrade**——券商提供的量化交易终端，Python API 下单，本地 Windows 常驻。这条路的依赖链我实测过了：`xtquant(Python 库，已装) → QMT 客户端（本机常驻）→ 券商行情/交易服务`。客户端不在线，xtdata/xttrader 全部不可用——而客户端的开通，绕不开**资金门槛**（各券商不同，常见 10 万档）。

技术栈的匹配好到不像话：QMT 是 Python + Windows，和我现有的栈零缝隙。xtdata 自带实时 L1 五档——监控器被东财间歇断连折磨的问题顺带终结。

**好消息说完了。坏消息是我算了算卡里的钱：差得远。**

## 二、第二个发现比门槛更狠：10 万门槛 ≠ 10 万策略资金

我的风险预算（D-009）从第一天就是按**金额**定的："10 万级别 -30% 不可接受"。体检公式（D-076）往回一算：

```
10 万门槛资金
  ├── 6.4 万 → 进策略（corrected，L=2 万可承受亏损约束下的最大投入）
  └── 3.6 万 → 现金缓冲（QMT 账户门槛垫 + 安全余量）
```

验证一下这个分配有多必要：10 万全投 corrected = 历史最大浮亏 **3.14 万**——恰好踩在我自己画的"10 万级别 -30% 不可接受"红线上。门槛资金不是策略资金，是**门槛垫 + 策略仓位**两部分。这笔账在我提出终点线之前就已经写在体检面板里了——只是我最近头昏，没抬头看它。

## 三、四周归因：防御策略接住了下跌，进攻策略全部倒在闸门下

四周归因（D-098/099）的数字：大盘阴跌 5.3% 的四周，四个影子账户**全部跑赢基准**（超额 +2.2%~+9.2%），红利账户 β=-0.49——防御风格在阴跌市是负相关资产。执行基建三项实测达标（费用 0.03~0.07%、成交偏差 ~0.1%、ST 敞口 0）。

而进攻型：六次检验（月频截面/尾盘/触板/早盘动量/游击双阈值/条件持有）**全部倒在闸门下**。第三次外部评审补了最后一块拼图：**期望收益是"买入难度"的单调函数**——唯一为正的格子（一字板/秒板）恰恰是买不到的，涨停溢价是排队溢酬不是预测溢酬。修正口径重跑后，样本外 -1.39%，CLOSED。

这六份负结果档案，是"验证工厂"叙事里最硬的部分：每个格子都是我的直觉提出、闸门审判、数据裁决——包括两次我自己写"通过"又被干净口径推翻的假阳性。

## 四、从模拟到实践的三线并行（钱没到位也能铺）

| 战线 | 内容 | 状态 |
|---|---|---|
| **筹资线** | 攒 10 万门槛资金 + 问券商 QMT 开通条件 | 我的战场，量入为出 |
| **技术预研线** | BrokerAdapter 接口抽取（shadow/qmt 双实现骨架）+ xtquant 预研笔记 | 本篇落地 ✅ |
| **样本外积累线** | 影子盘照跑：12-09 调仓、12-29 二次归因（8 周功效 ×√2） | 系统自动 |

**筹资期 = 免费的样本外积累期。** 等钱的日子不是空等——影子盘每多跑一天，期望带的校准就多一个观测点。12-29 的第二次归因，就是"等钱"变成"等数据"的第一次兑现。

## 五、真钱的第一步：2000 元先跑一个月

钱到位、QMT 开通——也不等于 10 万全进策略。alpha 还在"无法证实也无法证伪"状态（12-29 裁决），所以真实交易的第一步是 **2000 元真实实盘先跑一个月**：验证 QMT 执行链 + 真钱心理 + 期望带复测，再逐步放大到风险预算允许的 6.4 万。验证工厂的纪律走到真钱这一步，反而要更严。

## 尾：初衷回归

项目代号：QuantDex。初衷是"自动量化交易"。四周前我以为这个初衷已经跑偏——直到四周归因、三份外部评审、六格全灭的负结果档案全部落位，我才看清：**初衷一直没跑，跑的是我的注意力**。从模拟到实践的转变，缺的不是更多策略、不是更大的模型——是一个数字（10 万）、一通电话（券商条件）、一个接口（BrokerAdapter，本篇已落地）、和耐心。
