# QuantDex 分时执行设计模式（基于 A 股交易规则）

> 版本：v1.0 设计提案（未实施） · 2026-10-27
> 关联：D-034（T+1 开盘执行口径）、D-038（前瞻收益窗口修正）、D-039（策略注册表）、D-031（影子盘 A/B 方法论）
> 定位：回答一个问题——日级因子决定了「买什么」之后，如何在 A 股一天的交易时段内优化「何时买、怎么买」。
> **信号层一字不动**，本设计全部发生在执行层。

---

## 0. TL;DR（先读这段）

1. 信号保持日级（T 日收盘算因子、T+1 执行），在订单上新增一个维度 `execution_style`（执行风格），贯穿挂单、撮合、回测三处。
2. **最优先做的不是分钟数据，而是「收盘集合竞价」模式（P1-close_auction）**：成交价=收盘价，用现有日线数据就能精确模拟，零数据成本即可与现行 `next_open` 做 A/B。
3. 用户直觉"开盘未必是最佳买入时点"——对本项目数据目前**方向相反**：D-034 实测开盘口径全周期 +39.81% vs 收盘口径 +30.35%（现行版），开盘执行领先 ~9.5pp。机制见 §5.2。但这个优势没有扣除"真实排队的逆向选择成本"（影子盘按开盘价成交是乐观假设），结论待分钟数据与影子盘 A/B 检验。
4. 分钟线数据当前 **0 个文件**（接口具备、从未入库），所有分钟级模式（VWAP/TWAP/条件执行）一律排在数据管道之后，先回测后上线（项目铁律，D-026/D-022/D-033 三次"防御性规则回测翻车"的教训）。
5. 本策略是 20 日调仓、50 只等权、单票约 2 万元——分时层的量级是**执行成本与日内段收益归属**（年化估计 0.5~2pp），不是选股 alpha。不做盘中信号，不做激进市价单。

## 1. 背景与问题定义

### 1.1 现行链路（基线）

```
T 日 19:00  日级因子面板 → 目标权重 W（Top50 等权，经风控）
            → 挂单 pending（fill_date = T+1，参考价 = T 收盘）
T+1         _fill_pending 按【T+1 开盘价】撮合
            涨停买不进 / 跌停卖不出 / 停牌 → 拒单；现金硬校验 → 部分成交
```

### 1.2 被忽略的三个日内机会

| # | 机会 | 现状代价 |
|---|---|---|
| 1 | T+1 开盘价是「盲价」：挂单时不知道次日会高开/低开/一字板；真实世界里开盘集合竞价排队存在**逆向选择**（你的买单在上涨开盘时大概率排不到），影子盘按开盘价全额成交是乐观假设 | 执行成本被低估，回测/影子盘收益虚高 |
| 2 | T+1 盘中信息完全没用上：当日涨跌停封板/打开、停牌复牌、当日走势（低波冷门股当日若已大涨，追买价值下降） | 拒单语义过粗（开盘涨停一律拒，不复检） |
| 3 | 日内执行时点本身是一个**可优化的一级变量**：D-034 显示开盘 vs 收盘口径全周期差异最高 ~12pp 且方向不定 | 执行时点从未被当作研究对象 |

### 1.3 边界声明（诚实前提）

- 分时层**只优化执行，不改变信号**。凡是"盘中走势触发加减仓"的规则都属于信号层变更，必须走完整回测流程（历史上 D-022 入场过滤、D-026 个股止损、D-033 断路器三次全部负贡献——多动多亏是本策略族的既有证据）。
- 100 万 Top50 等权 → 单票 2 万元，占标的日成交额通常不足 0.01%，**冲击成本可忽略**，不需要拆单算法的"护盘"功能；拆单的意义只在平滑时点风险。
- 2000 元小账户单笔约 660 元、最低佣金 5 元/笔已占 0.75%——执行时点优化对它无意义，它继续承担执行链路验证职能。

## 2. A 股交易规则地基（设计的全部依据）

### 2.1 一个交易日的时间轴与逐段约束

| 时段 | 机制 | 挂单 | 撤单 | 对本系统的意义 |
|---|---|---|---|---|
| 09:15–09:20 | 开盘集合竞价（撮合不成交，只撮合出虚拟价） | 可 | **可** | 可试探性挂撤 |
| 09:20–09:25 | 开盘集合竞价 | 可 | **不可** | 挂单即锁死：挂前必须先判涨跌停/停牌 |
| 09:25 | 集合竞价撮合 → **产生开盘价** | — | — | 现行 next_open 的成交价即此价 |
| 09:25–09:30 | 申报暂存期 | 可（暂存） | 可（暂存，9:30 送撮合） | 可提前排队 |
| 09:30–11:30 | 连续竞价（上午） | 可 | 可 | 价格优先、时间优先 |
| 11:30–13:00 | 午间休市 | 券商可暂存 | 券商可暂存 | TWAP 必须跳过 |
| 13:00–14:57 | 连续竞价（下午） | 可 | 可 | **全日信息最全的可撤单时段** |
| 14:57–15:00 | **收盘集合竞价**（沪深两市统一，上交所 2018-08-20 起） | 可 | **不可** | 产生收盘价；挂单前必须完成全部判定 |
| 15:00–15:30 | 大宗交易（竞价市场隔离） | — | — | 与本系统无关（单票 2 万远不到门槛） |
| 15:05–15:30 | **盘后固定价格交易**（仅科创板 688 / 创业板 300·301） | 可 | 可 | 以当日收盘价撮合，无排队风险 |

### 2.2 涨跌幅限制矩阵（撮合判定依据）

| 板块 | 代码前缀 | 限制 | 备注 |
|---|---|---|---|
| 沪深主板 | 60 / 00 | ±10% | ST/*ST ±5%（**现行 `_board_limit` 未处理 ST，见 §7.5**） |
| 创业板 | 300 / 301 | ±20% | 注册制新股上市后前 5 个交易日无涨跌幅 |
| 科创板 | 688 | ±20% | 同上；另支持盘后固定价格交易 |
| 北交所 | 43/83/87/92 | ±30% | 不在沪深300 池内，本系统不会持有 |

现行 `_board_limit`（pipeline.py:54）已覆盖 10%/20% 两档，与撮合容差 0.1% 配合正确；缺口只有 ST 一档（§7.5）。

### 2.3 委托规则（挂单设计必须遵守）

- **数量**：买入必须 100 股（1 手）整数倍；卖出可含零股但零股须一次性卖出。现行 `LOT=100` 整手约束正确。
- **价格**：最小变动 0.01 元；20% 板块限价单四舍五入到分。
- **市价单**：沪市 2 种（最优五档剩余撤/剩余转限价）、深市 5 种，均需**保护限价**。本系统单票 2 万元，**不需要市价单**——限价单+保护带更可控。
- **科创板/创业板 2% 有效申报价格笼子**（主板没有）：连续竞价阶段限价申报不得高于买入基准价格的 102%、不得低于卖出基准价格的 98%。→ 未来任何"低吸限价"逻辑必须以最新价±2% 为边界，笼外废单。
- **撮合原则**：连续竞价价格优先、时间优先；集合竞价取可实现最大成交量的价格。

### 2.4 T+1 与资金规则

- 当日买入的股票**当日不可卖出**（对 20 日调仓周期无影响）。
- 卖出资金**当日可用于买入**（次一交易日可转出）→ "尾盘先卖后买"在同一交易日内可完成，现行 `_plan_orders` 先卖后买的顺序与资金规则一致。

### 2.5 程序化交易合规边界

按《证券市场程序化交易管理规定（试行）》（2024-10-08 施行）：通过程序自动生成并下达交易指令需向券商履行报告程序；高频标准（单账户每秒申报≥300 笔或单日≥20000 笔）远非本系统量级。**本系统当前为"收盘后生成挂单 + 人工/半自动执行"，不触发报告义务；升级为全自动下单（TODO P3）前必须先完成券商报备**——已列入 TODO 安全清单。

## 3. 三层架构：信号层 → 订单计划层 → 分时执行层

```
┌─ 信号层（不变）──────────────────────────────┐
│ 日级因子面板 → composite_topn / topk_dropout │
│ 输出：T 日收盘目标权重 W（T+1 执行）           │
└──────────────┬───────────────────────────────┘
               ▼
┌─ 订单计划层（小改）───────────────────────────┐
│ _plan_orders 整手化 + 先卖后买 + 缩单         │
│ 新增：每笔订单带 execution_style、T+1 执行窗  │
└──────────────┬───────────────────────────────┘
               ▼
┌─ 分时执行层（新增）───────────────────────────┐
│ 输入：execution_style + 该风格的执行窗        │
│ 职责：① 窗口前的"判定"（停牌/涨跌停/流动性）   │
│       ② 窗口内的"取价"（开盘价/收盘价/段VWAP） │
│       ③ 异常分支（拒单/顺延/部分成交）         │
│ 输出：fill_price / fill_time / fill_state     │
└───────────────────────────────────────────────┘
```

**核心抽象**：把「T+1 开盘价撮合」这一硬编码，泛化为「T+1 执行窗 + 窗口取价函数」。日级因子与执行时点解耦后，"一天中什么时候买"就变成了一个**可配置、可回测、可 A/B 的参数**，而不是一个写死在代码里的假设。

## 4. 执行模式库（Patterns）

每个模式给出：定义 / 成交价如何模拟 / 所需数据 / 规则约束 / 优缺点。

### P0 `next_open`（现行基线）
- **定义**：T+1 09:25 开盘集合竞价产生的开盘价成交（代码语义上等价于"开盘第一价"）。
- **模拟**：日线 `open`，零额外数据。
- **规则约束**：真实执行需在 09:15–09:25 挂限价参与竞价；09:20 后不可撤单，一字涨停会锁死资金（现行为"开盘涨停拒单"，略乐观——真实排队甚至进不了成交）。
- **优缺点**：✅ 最早建仓、吃到 T+1 全部日内段；✅ 数据零成本。❌ 盲价：竞价排队逆向选择未建模；❌ 无法复检盘中状态。

### P1 `close_auction`（收盘集合竞价）——**首推**
- **定义**：T+1 14:55 完成判定（停牌/涨跌停/流动性），14:56–14:57 挂限价单（保护带：最新价 ±0.5%），进入 14:57–15:00 收盘集合竞价，以**收盘价**成交。
- **模拟**：日线 `close`，**零数据成本、与真实撮合价完全一致**（收盘价就是竞价产物）。
- **规则约束**：14:57–15:00 **不可撤单** → 挂单前的判定必须完备（这是本模式的全部风险所在）；沪市极端情况下收盘竞价未产生价格则顺延连续竞价最新价（§7.4）。
- **优缺点**：✅ 全天信息可用（当日涨跌停、停牌、走势全部确定后再决定）；✅ 模拟精度全模式最高；✅ 收盘竞价成交集中，2 万单无冲击。❌ 放弃 T+1 日内段（建仓最晚）；❌ 卖单资金当日可再买、买单资金占用时间最短但错过当日行情。
- **与 D-034 的关系**：D-034 的"收盘执行"口径即本模式的历史可模拟版本——已有全周期数字（现行版 +30.35%），缺分年分布。

### P2 `tail_twap`（尾盘 TWAP）
- **定义**：T+1 14:30–14:55 等时拆 N=5 份限价单（每 5 分钟一份，按当时最新价 ± 保护带），按各份实际成交量加权得均价。
- **模拟**：5 分钟线段 VWAP，**需要分钟数据**。
- **规则约束**：跳过午休边界（不涉及）；14:57 后不得再拆；科创/创业标的限价须在 ±2% 笼内。
- **优缺点**：✅ 平滑时点风险，单点坏运气减半；❌ 模拟需要分钟数据（当前 0 文件）；❌ 收益相对 P1 边际改善有限（25 分钟内 VWAP ≈ 收盘价附近）。

### P3 `open30_vwap`（开盘后半小时延迟）
- **定义**：T+1 09:35–09:55 拆单执行，等开盘噪声（隔夜信息集中释放、散户情绪单）消化后成交。
- **模拟**：5 分钟线段 VWAP，需要分钟数据。
- **规则约束**：同 P2。
- **优缺点**：✅ 保留大部分日内段，规避竞价排队逆向选择；❌ 09:30–09:35 之间仍是盲执行。
- **定位**：P0 与 P1 的中间档，若研究显示"日内段收益为正但开盘竞价成本高"，此模式是最优折中的候选。

### P4 `cond_guard`（条件执行：涨跌停复检，改变口径，须先回测）
- **定义**：P0/P1/P2 任一模式之上叠加盘中状态复检：
  - 买单：开盘/尾盘涨停 → 现行直接拒单；本模式改为「盘中打开则按当日剩余窗执行，全天未打开则顺延至下一执行日」。
  - 卖单：跌停同理。
- **模拟**：需要分钟线或盘中快照采样（判断"封板/打开"），日线只能判"是否一字板"（open=high=low=close at limit → 必拒；否则有打开可能）。
- **规则约束**：顺延语义必须明确（顺延订单 fill_date=下一交易日，避免"用旧信号卡壳"）；一字板判定必须保守。
- **定位**：这是唯一**改变撮合口径**的模式（现行为无条件拒单），收益（减少无谓拒单造成的权重缺口）与风险（在打开的涨停板上接刀）都要靠回测定夺。**未回测通过前不实施**。

### P5 `after_fixed`（盘后固定价格，仅 300/301/688）
- **定义**：15:05–15:30 盘后固定价格交易，以收盘价撮合，可挂可撤。
- **模拟**：同 P1（收盘价），但仅覆盖部分标的。
- **定位**：不做主通道，只作为 P1 模式下科创/创业标的的**补充通道**（避开收盘竞价 14:57–15:00 不可撤单风险）。实施优先级最低。

### 明确不做（负面清单）

| 不做的事 | 理由 |
|---|---|
| 盘中限价低吸 / 网格 | 改变信号语义；D-026 已证明本策略族"按价格跌幅说话"负贡献 |
| 09:20–09:25 竞价抢单 | 不可撤单窗口 + 一字板锁死资金风险，收益不抵风险 |
| 市价单 | 单票 2 万无冲击需求，限价+保护带完全够用且更可控 |
| 日内信号因子（分时反转等） | 属研究线新课题（另起 vault/02-实验），不是执行层职责 |

## 5. 统一收益分解与回测验证框架

### 5.1 三段收益公式（D-034 两段公式的推广）

设执行时点为 $p_{exec} \in \{open, \ldots, close\}$，则 T+1 当日组合收益：

```
r_port = Σ w_old × r_隔夜        # 旧仓：T 收盘 → T+1 开盘
       + Σ w_old × r_[open→t]    # 旧仓：开盘 → 执行时点
       + Σ w_new × r_[t→close]   # 新仓：执行时点 → 收盘
       − 成本（换手部分）
```

- P0（open 执行）：`r_[open→t] = 0`，即 D-034 开盘口径；
- P1（close 执行）：`r_[t→close] = 0`，即 D-034 收盘口径；
- 中间时点（P2/P3）：需分钟数据构造段收益。

`portfolio.py` 改造：`open_prices` 参数泛化为 `exec_prices + exec_style`，保留旧参数向后兼容（05/06 全部脚本、回测面板自动随动）。

### 5.2 先验机制分析：为什么"早买"目前占优（以及哪里的结论不可靠）

**A 股日内收益结构的实证常识**：A 股长期呈现「隔夜收益偏负、日内收益偏正」的结构（与美股相反）。对多头组合：

- 开盘买入 = 新仓吃到 **T+1 全部日内段**（期望为正）；
- 尾盘买入 = 新仓不吃日内段，资金当日闲置。

这解释了 D-034 开盘口径领先收盘口径 ~9.5pp 的主要来源：**新仓的日内段收益归属**，而非选股差异。

**但开盘口径的两处水分**（这正是"分时研究"要挤掉的）：
1. 影子盘按开盘价全额成交 = 假设竞价排队必成——上涨开盘时买入单真实成交价劣于开盘价（逆向选择），卖出单则占优，净效应取决于方向分布；
2. 开盘 30 分钟是全天价差/波动最高时段（A 股 U 型成交量曲线），滑点常数 5bp 对开盘执行可能偏乐观。

**所以真正的实证问题**是：日内段收益 − 开盘执行的真实成本 > 0 是否成立、分年是否稳定。这是 §5.3 的研究对象，不是拍脑袋能定的。

### 5.3 三阶段检验设计（直接回答"一天中最佳买入时机"）

| 阶段 | 数据 | 做法 | 产出 |
|---|---|---|---|
| **S0 立即可做** | 现有日线 | 05/06 以 `exec_style=open` 与 `=close` 各跑一遍三策略，**分年**输出差异表（D-034 只有全期总数，无法看稳定性） | "开盘 vs 收盘"分年分布 → 若某口径分年稳定占优即为强信号 |
| **S1 分钟管道** | 5 分钟线（baostock，先小样本实测历史深度，再全池 949 只 × 近 60 交易日） | 11 个候选时点（9:35/9:45/10:00/10:30/11:00/13:05/13:30/14:00/14:30/14:45/14:55）的段 VWAP 执行差异分布；涨跌停打开/封板状态统计 | 日内执行差异热力图 → 最优执行窗；P4 模式的打开率数据 |
| **S2 影子盘 A/B** | 影子盘 | 注册表加第 5 账户（同因子同参数，仅 execution_style 不同——干净 A/B，复用 topk vs strict 的方法论） | ≥8 周真实执行价差与回测对照（11-20 偏差归因同窗口） |

**统计纪律**（吸收红利因子 D-027 教训）：S0/S1 的结论必须**分年方向一致**才可采纳；单一全期均值不作为切换依据。

## 7. 异常处理决策树（按 A 股规则逐条落）

| 场景 | 判定时点 | 处理 |
|---|---|---|
| T+1 开盘一字涨停买单 | 09:25（P0）/ 14:55（P1） | 一字板（open=high=low=close 且缩量）→ 必拒；P0 现行"开盘涨停即拒"保守正确，保持 |
| 涨停但盘中打开买单 | 14:55（P1 下当日收盘已非涨停 → 正常成交） | P1 天然解决 P0 的部分误拒；P4 进一步前置 |
| 跌停卖单 | 同上对称 | P1 口径下收盘仍跌停 → 拒单（真实世界也卖不出）；盘中打开 → 成交 |
| 停牌 | 挂单前（T 日收盘后即知） | 保持 pending（现行语义正确——"没数据 ≠ 停牌"的教训已入问题索引）；**禁止**改用旧价成交 |
| 14:57–15:00 撤单不可用 | 挂单前 | P1 挂单前置判定必须在 14:56 前完成：停牌检查、涨跌停检查、现金/持仓复核（webapp add_order 同一套校验） |
| 沪市收盘竞价未产生价格（极端） | 15:00 | fallback 连续竞价最新成交价；日报标注 |
| 科创/创业新股前 5 日无涨跌幅 | 挂单前 | 沪深300 调入新股需上市满一定时限，面板几乎不会出现；防御处理：无 prev_close → 拒单 |
| ST ±5% | 挂单前 | `_board_limit` 补 ST 判定（用 bs_securities/名称列表标记 ST），详见评审报告3 |
| 临时停牌（科创/创业新股 30%/60% 临停 10 分钟） | 盘中 | 停牌段不执行；复牌后（集合竞价）按剩余窗执行——仅在 P4 启用后有意义 |
| T+1 资金规则 | 挂单前 | 先卖后买顺序已符合（卖出资金当日可用）；P1 模式下同日完成买卖无 T+1 障碍 |

## 9. 风险与边界复述

1. **收益量级预期管理**：本设计的目标是把"执行层每年 0.5~2pp 的隐形损益"变成可测量、可优化的对象，不是找新 alpha。若 S0 显示 open/close 分年差异方向混乱，正确结论可能是"维持 next_open 不动"——**研究结论为"不切换"同样是合格产出**（D-022/D-033 先例）。
2. **收盘竞价集中执行**：50 只同时 14:56 挂单，当前单票 2 万对日成交额千万级标的可忽略；资金规模上到千万级需重估（写入 D-009 风险预算联动）。
3. **不可撤单窗口**是 P1 唯一的机制性风险，靠"挂单前完备判定"化解；该判定与现行 webapp add_order 校验共用一套逻辑，不新增孤岛。
4. **数据地基优先**：若评审报告3 的 qfq 复权断裂问题未修复，S0/S1 一切研究建立在坏价格上——**分时研究必须排在数据修复之后**（或至少并行修复、以修复后口径重跑）。
