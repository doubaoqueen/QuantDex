## 二、技术盘点（公开部分）

### 1. 因子体系

**13 因子选股体系**（社区干货帖）：
- 五维度：盈利（归母净利润/总净利润双口径）、现金流（经营/投资）、质量（流通比/研发强度×2源）、规模（总资产/流通市值×2源）、换手技术（长期换手/换手波动/量价背离）
- 预处理四件套：**分位截断去极值**（单因子前后 0.1%，量价可放宽 0.5%/99.5%——明确说不用 3σ）→ Z-score → 行业+市值中性化（回归取残差）→ 方向统一
- 组合：等权合成 → Top100 等权 → **每 5 日调仓**
- 五层过滤：非ST、价>1.2 元（排仙股）、上市满 365 天、剔北交所、剔科创板
- 提到但未实施的高阶：行业偏离 ±3%、单票上限 2%、换手率上限 30%
- 值得注意的成本意识："千一双边成本、一年约 25% 摩擦成本"

**RF 特征筛选流程**（社区帖）：
1. 候选因子"无脑全放入"随机森林 → 标签 = 未来 **5 日收益率**
2. 取特征重要性 Top20 → 逐因子做 IC 分析（按 |IC 均值| 排序）+ 因子间相关性分析
3. 入选标准：高 IC + 与其他因子低相关 → 按重要性赋权合成新因子
4. 调仓 5 日 → 参数优化后改 6 日

**Alpha101/191 教程化**：官方教程把 WorldQuant Alpha101、国泰君安 Alpha191 全部用 SQL 表达式引擎复现（`pct_rank_by(date,x)` 横截面排名、`m_corr/m_stddev/m_decay_linear/m_lag` 时序算子、`AVG() OVER (PARTITION BY industry_code,date)` 行业中性化、`ABS(x)/SUM(ABS(x)) OVER` scale）。分析框架：全市场十分组分层 + 日 IC/22 日 IC 均值/累计 IC + 多空组合回测（基准中证500）。Alpha101 特点结论：交易型量价 Alpha，平均持有期 0.6–6.4 天，因子间相关性低（平均 15.9%）。

### 2. ML / AI 层（他们的核心卖点）

- **20 连 ML 教程**（模板库机器学习系列）：线性回归（预测收益/上涨概率/构建因子）→ 逻辑回归 → 岭/Lasso/弹性网络 → SVM → KNN → 朴素贝叶斯 → 感知机 → 随机森林 → AdaBoost → XGBoost → DNN → CNN → LSTM → 滚动训练（线性回归/XGBoost/DNN 各一）
- **StockRanker**：list-wise 排序学习（GBDT 优化），多特征 → 股票排序，平台招牌
- **Transformer 选股**（公开度最高的一篇，参数完整）：

| 参数 | 值 |
|---|---|
| 结构 | **encoder-only**（无解码器）：输入映射 → 可学习位置编码 → 8 头多头注意力 × 3 层 → 全连接输出 |
| 输入维度 | **98 特征**：量价类（当日及滞后 1–4 期的 close/open/high/low/成交额/换手率/收益率）+ 统计类（5 日均值/最大/最小/标准差/滚动排名/线性衰减）+ 相关系数类（量×价 5 日相关） |
| 标签 | **未来 5 日收益** `m_lead(close,5)/m_lead(open,1)-1`——次日开盘买入口径，**与我们的 D-034 同款**；MSE 回归；标签 1%/99% 分位截断 |
| 训练 | 2022–2024 训练 / 2025 测试；归一化参数**只用训练集拟合**（防泄露）；AdamW(wd=0.01) + 余弦退火 + 梯度裁剪 1.0 + 早停 patience=5 |
| 接入 | 预测值排名 → Top20 等权 → 每 5 日调仓；成本买 0.01%/卖 0.08%；基准沪深300 |
| 未公开 | 序列窗口构造细节、验证集划分、滚动训练机制、权重文件 |

- 高频因子构建教程（窗口函数性能优化、数据降频、边加工边存表）
- 研报复现：Fama-French 三因子 A股实证（德邦）、PATV"持续异常交易量"因子（招商）、高频成交额 Alpha（华安）

### 3. 策略面（120 套公开模板的分布）

新手 ~24（含 5 套小市值变体、ST 摘帽事件、2进3 打板）｜事件型 10｜交易逻辑 9（调仓日/权重/止盈止损/大盘风控）｜单/多因子 17｜因子构建 20｜机器学习 20｜研报复现 3。另有社区实盘帖（如"实盘 1 年 228%"反包策略）——**核实为付费引流广告，公开部分零干货**（只透露用了 StockRanker + T+1 高换手），这类帖子是他们社区的常态，看标题即可，不必当真。

### 4. 生态面

比赛（BigAlpha 三赛道：因子挖掘/端到端大模型/AI 开放创新）、AI 工具线（Cowork 投研助手/AlphaGPT/Hermes Agent）、AI 代码助手（兼容 QMT/PTrade/聚宽）。

## 三、与 QuantDex 对照

| 他们有 | 我们有 | 差距判定 |
|---|---|---|
| SQL 表达式因子引擎 + Alpha101/191 教程 | 47 个表达式因子工厂（expr_factors.py，学 qlib） | **同源、不落后**——我们的算子集等价（Ref/Mean/Std/Corr/Skew/Greater/Delta），缺的只是 Alpha101/191 这批"现成表达式库"本身 |
| 预处理四件套（分位截断→Z-score→中性化→方向统一） | 11_neutralize_factors.py（市值/行业中性化）；去极值口径未统一成流水线 | 小差距——把四件套固化进因子面板构建即可 |
| RF/XGBoost 特征筛选 + 重要性赋权合成 | 无（roadmap："多因子合成 + LightGBM"） | **中等差距**——特征矩阵（55 因子面板）已备好，缺模型层 |
| StockRanker / Transformer 排序选股 | 无（本次调研为接入预留，见 §四） | **最大差距**——但公开细节足以让我们起步 |
| 组合优化器、归因分析 | 等权 TopN + 漂移；归因在 D-068 排期 | 中等 |
| 数据广度（舆情/盈利预期/期货/可转债） | A股 949 PIT 成员；财务/估值示例级（P1-a/b 待补） | 大差距，但受"个人项目、数据源免费"约束 |
| BigTrader 券商实盘 | 影子盘 only（纪律：先影子盘 4 周 + 偏差归因） | 有意为之，顺序是对的 |
| 1000+ 策略源码 / 社区 / 比赛 | 决策日志 82 条 + 实验存档 49 份 + 全链路自研 | 性质不同：他们的模板大而无验证；我们每条都有 D 编号与 FDR 纪律 |

**反超项**（方法论层面）：PIT 五点核验、FDR 诚实（他们 IC 榜 ★=|t|>2 与我们修正前犯同样的错）、成本校准（D-067）、口径一致性（D-034 12pp 事故教学）、影子盘真记账 + 事故复盘文化。他们的公开帖大量出现"绩效如图（图缺失）"“详情付费"——我们的量化学院每条数字可追溯到 D 编号。

## 四、Transformer / attention 预留位（不实现，只留位置）

### 公开线索汇总
上面 §2 的 Transformer 参数表是他们公开度最高的 AI 策略文档；第二篇（4wqCcaD41I）只有概念介绍，深度内容在付费课程/直播里。BigAlpha 大赛 2026 设"端到端大模型"赛道——attention 在他们体系里是**序列模型替代树模型做收益预测**，不是另类数据 NLP。

### QuantDex 接入设计草案（等 LightGBM 基线跑通后启动）

1. **位置**：`src/strategies/attention_ranker/`（新模块，与 multi_factor.py 并列）；数据消费 `build_factor_panel` 的 T×N 因子面板——55 个表达式因子天然就是特征，**input_dim≈55**（他们用 98 个手工特征，我们用因子面板等价）
2. **标签**：沿用 D-034 开盘口径 `future_ret = lead(open,5)/lead(open,1)-1`，1%/99% 分位截断——与回测/影子盘口径零漂移（这是我们的强项，别学他们文档里语焉不详的口径）
3. **起步形态**：encoder-only + 可学习位置编码，d_model 64、nhead 4、2 层起步（他们 128/8/3 是 32C/64G 云端配置，本机 14600KF 先缩配）；回归 MSE 起步，第二步再试 list-wise 排序损失（对标 StockRanker）
4. **防泄露纪律**（比模型结构更重要）：归一化参数只拟合训练窗；**滚动训练**必须做（对齐 06_walkforward 的逐年重选参范式，他们的教程也单独做"滚动训练"系列）；测试期严格样本外
5. **准入门檻**：沿用 D-073 三关——经济先验（attention 解决什么：横截面因子间交互 + 时序依赖，理论上比等权合成强在哪要写得出来）→ WF 样本外 → 组合增量证据（vs 现行等权合成 + vs LightGBM 基线，至少跑赢后者才值得上线）
6. **实验存档**：每次训练存 experiments/*.json（结构/超参/数据窗口/样本外指标），衔接 qlib 式复现

### 顺序建议
RF/XGBoost 特征筛选（§三表格的中等差距项）→ LightGBM 排序基线 → attention。attention 是"锦上添花"不是"从 0 到 1"——没有树模型基线，无法回答"attention 带来了多少增量"，这正是 D-073 第三关的要求。
