# tests/ — 回归测试

零依赖断言测试（函数名兼容 pytest；环境未装 pytest 时用自带运行器）。

## 运行

```bash
python tests/run_tests.py       # 全部测试
python -m pytest tests/         # 若安装了 pytest 亦可
```

## 覆盖范围

| 文件 | 覆盖 |
|---|---|
| `test_backtest_engine.py` | 单标的引擎：T+1 成交（前一日仓位 × 当日收益）、建仓/平仓成本、卖出印花税、空仓零收益 |
| `test_portfolio_engine.py` | 组合引擎：T+1 生效、**权重漂移**、换手成本、卖出印花税、现金仓位、空输入报错 |
| `test_risk.py` | 风控：单票截断、总仓位约束、回撤断路器（未达阈值不触发 / 触发后按比例降仓） |
| `test_ledger.py` | 账本：建表、写入快照/持仓/成交、读回、WAL 模式 |

## 约定

- 测试用**独立手算实现**与引擎结果逐日对拍（rtol=1e-12），改动成本/成交口径时会被立即发现；
- 新增成本项（如冲击成本）时：先加断言、再改引擎。
